# Контент по слайдам на вкладке «Сценарий»

Читай при просьбе записать подготовленные слайды в Google Sheets. Пользовательская команда «занеси на вкладку Сценарий» означает запись в карточку текущего проекта со строки **60** в формате ниже. Не запрашивай образец заново.

## Назначение и границы

- Используй таблицу текущего проекта из команды или контекста. Если её ссылка неизвестна, уточни только карточку проекта.
- Через подключённый Google Drive прочитай метаданные и найди фактическое название вкладки: например, `5. Сценарий` или `Сценарий`. Используй её актуальный `sheetId`, не переноси ID вкладки из другого проекта.
- Перед записью прочитай целевой диапазон с формулами, примечаниями, валидацией и форматами; проверь существующие объединения. Следуй навыку Google Sheets для точечных изменений.
- Начинай блок с A60. Строки 1–59 и посторонние данные за границами блока сохраняй. Новые строки со сдвигом всего листа для обычной записи не нужны.
- Если с 60-й строки уже находится прежний блок этого сценария, обнови его в пределах запрошенных дней, сохраняя остальные. Повторный запуск не должен создавать дубликат ниже. Если там находятся посторонние данные, уточни конкретный конфликт перед их заменой.

## Столбцы и строки

Это обычный форматированный диапазон A:D с объединениями, а не объект native Table.

- **A — «Слайд / текст на слайде».** Одна ячейка: `Слайд № N`, затем пустая строка, затем полный текст для экрана с исходными переносами строк. Нумерация начинается с 1 в каждом дне.
- **B — «Оформление».** Конкретное задание на оформление. Непросмотренное изображение описывай как нужный пример для подбора.
- **C:D — «Заметка докладчика».** C и D объединены горизонтально в каждой строке. Текст записывается в C, D остаётся пустой. В C — готовая речь с абзацами, без редакционных указаний и фраз «в интервью я говорю».

Верх блока:

1. **A60:D60 объединены:** `КОНТЕНТ ПО СЛАЙДАМ`.
2. **A61:D61 объединены:** короткая служебная строка о фактическом составе блока: число дней и слайдов либо важная согласованная особенность. Не копируй комментарий из чужого проекта.
3. **Строка 62:** A — `Слайд / текст на слайде`; B — `Оформление`; C:D объединены — `Заметка докладчика`.
4. **С 63-й строки:** полоса `День X — точная тема дня`, объединённая A:D; далее каждый слайд занимает одну строку по схеме A / B / C:D.
5. Следующий день идёт сразу после предыдущего блока; его заголовок также объединён A:D. Не оставляй пустые резервные строки для отсутствующих слайдов.
6. При количестве, отличающемся от трёх, после слайдов дня добавь отдельную служебную строку A:D с инструкцией переноса из `content-slides.md`. Это не слайд и не часть речи.

Количество дней и слайдов определяется заданием и материалом. Например, для 3/4/3/3/4 слайдов с двумя служебными строками весь блок занимает A60:D86. Это пример расчёта, не постоянный размер диапазона.

## Оформление диапазона

- Arial; основной текст 10 pt, выравнивание влево и вверх, перенос текста `WRAP`.
- Номер и экранный текст в A — полужирные; оформление в B и речь в C:D — обычные.
- Заголовок блока — 14 pt, полужирный; полосы дней — 11 pt, полужирные. Фон этих строк `#E8EAED`, вертикальное выравнивание по центру.
- Шапка столбцов — 10 pt, полужирная, фон `#F2F3F5`.
- Содержательные строки — белый фон, текст `#202124`, тонкие горизонтальные границы `#DADCE0`.
- Служебные строки — 10 pt, курсив, цвет `#5F6368`.
- Сохраняй существующую ширину столбцов карточки: изменение всей колонки влияет и на верхнюю часть листа. Ширину для речи даёт объединение C:D. Подбери высоту только строк нового блока по длине текста и проверь отсутствие обрезки в Google Sheets; для объединённых ячеек не полагайся только на автоматическую высоту.
- Источники и названия разделов интервью при необходимости помести в примечание ячейки C, отдельно от речи. Не добавляй дополнительные столбцы без запроса.

## Запись и проверка

1. Подготовь весь контент, карту строк и точный диапазон. Сохрани утверждённые темы и последнюю согласованную редакцию слайдов.
2. Запиши значения, точечное оформление и объединения через Google Sheets connector. Формат образца воспроизводи без переноса его текстов, сюжетов и ссылок.
3. Повторно прочитай весь записанный диапазон. Сверь каждый текст, абзацы, номера, темы, поля оформления, количество слайдов, объединения и форматы. Проверь соседние ячейки на сохранность.
4. Просмотри результат в Google Sheets: заголовки, длинные заметки и границы дней должны читаться без обрезки. Исправляй только подтверждённые проблемы внутри блока.
5. В финале дай ссылку на вкладку с точным диапазоном и сообщи число дней и слайдов. Не дублируй весь сценарий в чате, если пользователь этого не просит.

Ссылка хранится как образец оформления, а не как целевая таблица; для очередной записи достаточно этого описания.
