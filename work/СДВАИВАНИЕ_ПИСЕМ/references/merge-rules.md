# Правила сдваивания регистрационных писем RU/EN

## Результат

На входе:

- письмо №0-а — варианты бесплатного и платного участия;
- письмо №1 — регистрация, старт сегодня;
- письмо №1-А — регистрация, старт завтра, может отсутствовать.

На выходе:

- №0-а + №1 — единое письмо для старта сегодня;
- №0-а + №1-А — единое письмо для старта завтра.

## Структура объединённого письма

Сохранять такой порядок блоков:

```text
Subject / Тема
Preheader / Прехэдер

Поздравление с регистрацией

Подарок и кнопка скачивания, если есть в исходнике

Первый эфир: день и время
Ссылка на эфир или сообщение, что ссылка придёт в следующем письме

Материалы и личный кабинет
Фраза «нет материалов — всё равно приходите»

День 1 — что рисуем
Чему научитесь — буллеты ✔️
Плейсхолдеры изображений

За N дней марафона вы — буллеты ✅
Бонусы
Обратная связь по работам

Два варианта участия
Бесплатно — буллеты ✔️
Подписка — буллеты ✔️
Кнопка подписки

Напоминание про письма
Соцсети только в EN
Подпись
```

Между смысловыми блоками оставлять одну пустую строку. Внутри списка пустых строк не добавлять.

## Время

Для школы Собака-Рисовака / Drawing Dog:

- RU: `19:00 МСК`;
- EN: `4pm GMT/UTC`.

Если вся текущая серия явно использует другое время, сохранить подтверждённое время серии. Для Red Point School типичное исключение: `2pm GMT/UTC` и `5pm МСК`.

## Бесплатное участие и срок доступа

Для 5-дневного марафона использовать дословно:

```text
✔️ Записи эфиров доступны, пока идёт марафон (8 дней)
✔️ Broadcast recordings available while the marathon is running (8 days)
```

Для 3-дневного марафона использовать дословно:

```text
✔️ Записи эфиров доступны, пока идет марафон (7 дней).
✔️ Broadcast records are available while the marathon is running (7 days).
```

Это полный срок доступа, включая дни марафона. Для другой длительности срок не угадывать.

Последний пункт бесплатного варианта зависит от версии.

Сегодня:

```text
✔️ Ничего делать не нужно — приходите сразу в эфир по ссылке из данного письма
✔️ Nothing to do — just join the broadcast directly via the link in this email
```

Завтра:

```text
✔️ Ничего делать не нужно — ссылка на первый эфир придёт в следующем письме
✔️ Nothing to do — the link to the first broadcast will arrive in the next email
```

## Соцсети и Telegram

Из RU полностью удалить Instagram, Telegram-канал, ВКонтакте, Facebook и задания поставить лайки.

Из RU и EN удалить Telegram-чат участников и аналогичные формулировки, включая:

```text
[Телеграм-чат участников] (ссылка)
[Telegram participants’ chat] (link)
```

В EN оставить только этот блок:

```text
Subscribe so you never miss new marathons and lessons:
▪️ [Instagram] (https://www.instagram.com/drawingdog.school)
Like any 3 posts — so the algorithm knows to keep showing you our content.
```

## Содержание и оформление

- Не искажать факты текущего проекта.
- Использовать ✅ только для результатов марафона, ✔️ для прочих списков, ▪️ для нейтральных перечислений.
- Ссылки писать обычным текстом: `[Название] (URL)`, без гипертекста.
- Изображения обозначать плейсхолдерами в квадратных скобках: `[картина]`, `[Эскиз]`, `[Референс]`, `[painting]`, `[Sketch]`, `[Reference]`.
- Не добавлять markdown-звёздочки, `---` или заголовки через `#` в ячейки.
- Заголовки обоих объединённых писем в RU и EN: жирный шрифт, чистая жёлтая заливка `#ffff00`.
